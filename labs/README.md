# Applied Cloud Operations (ACO-101) - Labs

This directory contains the lab materials for the Applied Cloud Operations (ACO-101) cohort.

## Labs

1. **Lab 0 - Environment Setup** (10 points)
   Set up and verify your local cloud operations toolchain, including container tooling, a working shell environment, and access to the shared repositories used during the cohort.

2. **Lab 1 - Deploying to Kubernetes** (20 points)
   Take a containerized workload from build to deploy, using a CI/CD pipeline to publish the image and then deploying and operating it on the Kubernetes cluster.
